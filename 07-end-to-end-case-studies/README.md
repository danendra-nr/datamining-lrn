# 07. End-to-End Case Studies

Kumpulan studi kasus terapan yang mengintegrasikan seluruh tahapan data mining, mulai dari ingestion data mentah, pembersihan, feature engineering, pemodelan, hingga evaluasi performa.

## Studi Kasus

- [`credit-risk-assessment/`](./credit-risk-assessment/): Penilaian risiko kredit perbankan menggunakan dataset relasional multi-sheet Excel, penggabungan fitur (relational join), penanganan kelas timpang (imbalanced class), dan klasifikasi default menggunakan Random Forest.
