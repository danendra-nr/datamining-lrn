# 04. Supervised Learning

Bagian ini membahas algoritma pembelajaran terarah (supervised learning) yang terbagi menjadi tugas **Regresi** (target kontinu) dan **Klasifikasi** (target diskrit/kategorikal).

## Topik dan Studi Kasus

### 1. Regression (`regression/`)
- [`car-price-prediction/`](./regression/car-price-prediction/): Prediksi harga mobil bekas menggunakan Linear Regression dan Ridge Regression beserta metrik evaluasi MAE, RMSE, dan R2 score.

### 2. Classification (`classification/`)
- [`customer-churn-prediction/`](./classification/customer-churn-prediction/): Klasifikasi retensi/churn pelanggan menggunakan Random Forest Classifier, evaluasi confusion matrix, precision, recall, dan ROC-AUC.
