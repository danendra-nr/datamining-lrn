# 05. Unsupervised Learning

Bagian ini berfokus pada algoritma pembelajaran tanpa label (unsupervised learning) untuk mengenali pola tersembunyi, segmentasi klaster, dan struktur data.

## Topik dan Studi Kasus

- [`customer-segmentation-kmeans/`](./customer-segmentation-kmeans/): Segmentasi profil nasabah/pengunjung mall berdasarkan skor pengeluaran dan pendapatan tahunan menggunakan algoritma K-Means serta Elbow Method.
