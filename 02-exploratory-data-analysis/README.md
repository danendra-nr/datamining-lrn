# 02. Exploratory Data Analysis (EDA)

Bagian ini membahas teknik eksplorasi data untuk memahami karakteristik statistik, distribusi fitur, dan korelasi antar variabel sebelum pemodelan.

## Topik dan Studi Kasus

- [`house-price-eda/`](./house-price-eda/): Studi kasus analisis distribusi harga properti, korelasi fitur fisik terhadap nilai pasar, serta visualisasi multivariat.
